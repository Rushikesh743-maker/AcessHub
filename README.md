# 🌍 AccessHub - Inclusive Web

AccessHub is a web-based platform designed to make learning, interaction, and games accessible for everyone. It provides accessibility tools, educational games, voice-controlled quizzes, and a resource hub tailored for users with dyslexia, color blindness, or other learning differences.

---

## Features

### Accessibility Toolbar
- **Text Size Control**: Increase or decrease text size for readability.
- **Easy Read Mode**: Simplified content for better comprehension.
- **Contrast Modes**: High contrast, Deuteranopia-friendly, Tritanopia-friendly.
- **Font Options**: Dyslexia-friendly OpenDyslexic font or Arial.

### Text-to-Speech
- Listen to content with word-by-word highlighting.
- Helps users with reading difficulties.

### Maze Game
- Navigate a maze using arrow keys or voice commands (`up`, `down`, `left`, `right`).
- Tracks level, time, score, and badges.
- Confetti animation on level completion.

### Memory Game
- Match shapes and symbols.
- Works well for colorblind accessibility.

### Voice Quiz
- Answer quiz questions using voice commands (`Option A` or `Option B`).
- Interactive quiz experience with instant feedback.

### Community Stories
- Share accessibility experiences.
- View stories submitted by other users.

### Resource Hub
- Collection of accessibility guides, tools, and references:
  - [WebAIM: Web Accessibility](https://webaim.org)
  - [W3C Accessibility Initiative](https://www.w3.org/WAI/)
  - [NVDA Screen Reader](https://www.nvaccess.org/)
  - [Apple Accessibility](https://www.apple.com/accessibility/)
  - [Microsoft Accessibility](https://www.microsoft.com/en-us/accessibility)

###Technologies Used

HTML5 – Semantic markup and structure.
CSS3 – Styling, responsive design, hover/focus effects.
JavaScript (ES6) – Logic for accessibility, games, voice quiz, TTS.
Canvas Confetti – Celebration effect on maze completion.
OpenDyslexic Font – Dyslexia-friendly reading experience.
